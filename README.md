# xHCI-Driver-for-Windows-7
用于Win7的USB3.X通用驱动

说明：
1、本驱动包含32位和64位版本，请选择相应的版本，用Dism++导入驱动，或者直接在设备管理器中更新驱动程序，也可以用pnputil工具导入。
2、Win7系统需要至少安装KB2864202 KB2990941 KB3087873 KB4490628 KB4474419这些补丁才能安装此驱动，其中KB4474419为最新的SHA2补丁，而安装KB4490628是安装KB4474419的先决条件，实测这两个补丁也可以用其他旧版SHA2补丁（如KB4012215）代替。
3、压缩包内的HCS文件夹为Intel的USB主控切换器驱动。虽然这是USB3.X通用驱动，但实测在Intel的7系/8系/9系主板（如B75/Z77/H77/X79/HM76/HM77/H81/B85/Z87/HM86/HM87/QM87/H97/Z97/X99等芯片组）的平台上安装时必须安装这个HCS驱动，否则系统会让主板上的USB2.0控制器接管USB3.0接口（尽管设备管理器能正确识别USB3.0控制器），导致速度下降。由于Intel的其他主板不包含USB2.0控制器，且AMD等其他品牌的主板上的USB2.0/3.X控制器是相互分离的，因此其他平台无需安装此HCS驱动。
4、此压缩包内的所有驱动都已经过数字签名，但考虑到部分电脑的win7系统可能没有更新根证书列表而提示驱动未签名，因此特意附上注册表文件OnlineCertificates.reg，双击导入即可更新根证书。如果用户对此注册表文件的安全性存疑，也可在联网状态下打开压缩包内的任意一个cat文件，稍等片刻系统出现了相应对话框即表明已联网更新根证书列表，可开始安装驱动。注意：如果需要通过Dism++给系统离线导入驱动程序，请务必集成上述几个系统补丁，并且在Dism++的【系统优化】界面单击【导入配置】并选择OnlineCertificates.reg文件，否则该驱动在系统启动后可能无法正常起效！
5、压缩包内的inf文件由本人编写或修改，其中添加了多语言支持，以及对大量主流品牌的USB3控制器的硬件ID的识别。若发现有翻译错误或者其他编写不合理之处，请与本人联系。请注意，该驱动是USB3.X通用驱动，usbxhci.inf中添加的不同厂商的硬件ID仅仅用于在设备管理器中显示USB控制器品牌，对驱动的实质功能没有任何影响。若检测到了inf中未定义的USB3控制器硬件ID，设备管理器中将显示“符合 xHCI 标准的 USB 主机控制器”。
